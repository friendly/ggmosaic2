# Geom proto

Geom proto

## Value

A `ggproto` object inheriting from
[`ggplot2::Geom`](https://ggplot2.tidyverse.org/reference/Geom.html),
used internally by
[`geom_mosaic_jitter()`](https://friendly.github.io/ggmosaic2/reference/geom_mosaic_jitter.md)
to draw jittered points within mosaic plot cells. Not intended to be
called directly.
