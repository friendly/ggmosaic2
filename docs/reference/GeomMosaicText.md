# Geom proto

Geom proto

## Value

A `ggproto` object inheriting from
[`ggplot2::Geom`](https://ggplot2.tidyverse.org/reference/Geom.html),
used internally by
[`geom_mosaic_text()`](https://friendly.github.io/ggmosaic2/reference/geom_mosaic_text.md)
to draw text/label annotations on mosaic plot cells. Not intended to be
called directly.
