# Geom proto

Geom proto

## Value

A `ggproto` object inheriting from
[`ggplot2::Geom`](https://ggplot2.tidyverse.org/reference/Geom.html),
used internally by
[`geom_mosaic()`](https://friendly.github.io/ggmosaic2/reference/geom_mosaic.md)
to draw the mosaic tile rectangles. Not intended to be called directly.
