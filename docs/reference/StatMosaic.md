# Geom proto

Geom proto

## Value

A `ggproto` object inheriting from
[`ggplot2::Stat`](https://ggplot2.tidyverse.org/reference/Stat.html),
used internally by
[`stat_mosaic()`](https://friendly.github.io/ggmosaic2/reference/geom_mosaic.md)
(and
[`geom_mosaic()`](https://friendly.github.io/ggmosaic2/reference/geom_mosaic.md))
to compute the rectangle boundaries and cell statistics for a mosaic
plot layer. Not intended to be called directly.
