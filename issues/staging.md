# ggmosaic2: Staging / publishing

`ggmosaic2` is unique among packages I've worked on because I'm essentially trying to replace the existing
package with this new one, due to the unresponsiveness of the original authors.
Not at all the same as Hadley's switch from `ggplot` - `ggplot2`

By comparison, for `ggbiplot`, I worked with the original author, to develop further, and maintain,
a package he had originally developed as student work (similar to Haley Jeppson), but then
abandoned. The result was that I essentially became the maintainer, retaining Vincent Q. Vu as first author.

So, how to do this without stepping on toes of those previously involved?

- Asked a question about this on gg-extenders discussion

- Kept all previous authors / contributors listed in ggmosaic2
